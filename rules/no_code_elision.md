# Rule: No Code Elision
เวลาที่ต้องเขียนโค้ดเพื่อนำไปอัปเดตหรือแก้ไขไฟล์ ห้ามย่อโค้ด หรือตัดทอนโค้ดโดยเด็ดขาด

**สิ่งที่ห้ามทำ:**
- ห้ามใช้คอมเมนต์ประเภท `// ... existing code ...`
- ห้ามละเว้นส่วนของฟังก์ชันที่ไม่ได้แก้
- ห้ามเขียนแค่โค้ดบางส่วนแล้วให้ผู้ใช้เอาไปประกอบเอง

**สิ่งที่ต้องทำ:**
- ต้องสร้างโค้ด (หรือส่งโค้ด) ออกมาให้ **ครบถ้วนสมบูรณ์ตั้งแต่ต้นจนจบไฟล์** (หรือครบทั้งบล็อก) เสมอ เพื่อให้สามารถคัดลอกหรือนำไปแทนที่ไฟล์เดิมได้ทันทีโดยไม่เกิดความผิดพลาด
