# Rule: Debug via Logging First
เมื่อผู้ใช้ขอให้ช่วยหาสาเหตุของบั๊กหรือปัญหาการทำงาน ห้ามสุ่มแก้ไขโค้ดหลัก (Guess & Fix) โดยพลการทันที

**แนวทางปฏิบัติที่ต้องทำ:**
1. ให้ทำการเพิ่มคำสั่ง `console.log()` (สำหรับ JavaScript/TypeScript) หรือ `print()` (สำหรับ Python/อื่นๆ) ในจุดที่น่าสงสัยก่อน
2. เพื่อตรวจสอบค่าตัวแปร (Variables) และกระแสการทำงาน (Control flow)
3. เมื่อได้ผลลัพธ์จาก Log แล้ว จึงนำมาวิเคราะห์หาสาเหตุที่แท้จริง และนำเสนอแผนการแก้ไขต่อไป
