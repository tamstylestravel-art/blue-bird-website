name: Mobile First UI Design
description: บังคับให้ AI เขียน UI โดยคำนึงถึงมุมมองมือถือเป็นหลักเสมอ (Mobile-first approach)
---

# Rules
1. **Mobile-First CSS:** เมื่อมีการสร้างหรือแก้ไข UI โดยใช้ Tailwind CSS ให้เขียนคลาสพื้นฐานสำหรับหน้าจอมือถือก่อนเสมอ (เช่น `text-base p-4 flex-col`).
2. **Breakpoints for larger screens:** การใช้ Breakpoints (`sm:`, `md:`, `lg:`) ให้ใช้เพื่อ "ขยายขนาด" หรือ "เปลี่ยน Layout" สำหรับหน้าจอแท็บเล็ตและเดสก์ท็อปเท่านั้น
3. **Prevent Overflow:** ห้ามใช้ขนาด `w-[...]`, `h-[...]`, `text-[...]` ที่มีขนาดใหญ่ตายตัว (Fixed size) หรือกว้างกว่าหน้าจอ 400px (มุมมองมือถือมาตรฐาน) หากใช้ต้องมี `max-w-full` หรือลดขนาดลง
4. **Mental Verification:** ต้องตรวจสอบลอจิกเสมอว่าบนหน้าจอที่แคบระดับมือถือ จะไม่มีองค์ประกอบใดล้นขอบจอ, ทับซ้อนกันจนไม่สวยงาม, หรือข้อความถูกบีบจนอ่านไม่ออก.
5. **Interactive Elements:** ปุ่มและลิงก์ต่างๆ ควรมีความสูงและพื้นที่ให้แตะได้ง่ายบนมือถือ (อย่างน้อย 44px - 48px).
